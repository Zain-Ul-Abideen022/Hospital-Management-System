
# 🏥 Hospital Management System (Console-Based)

A console-based Hospital Management System developed in C++ using Object-Oriented Programming (OOP) File Handling,Templates, STL Vectors, Exception Handling, and Operator Overloading.

This project simulates a basic hospital management system where users can manage patients, doctors, appointments, medicines, and billing through a menu-driven console application.

---

## Features

### Patient Management
- Add Patient
- View Patient
- Update Patient
- Delete Patient
- Automatic Patient ID Generation

### Doctor Management
- Add Doctor
- View Doctor
- Update Doctor
- Delete Doctor
- Automatic Doctor ID Generation

### Medicine Management
- Add Medicine
- View Medicines
- Medicine Quantity Management

### Appointment Management
- Book Appointment
- View Appointments
- Update Appointment
- Delete Appointment
- Prevents duplicate appointment booking for the same time slot

### Billing System
- Doctor Fee
- Test Fee
- Medicine Charges
- Automatic Total Bill Calculation

### File Handling
- Saves all Patients
- Saves all Doctors
- Saves all Medicines
- Saves all Appointments
- Automatically loads data when the program starts
